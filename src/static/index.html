Honest Security Model & Known Limitations

          

            

              1. Discretionary Access Control (DAC): The harness validates Linux POSIX DAC permissions
              between non-root UIDs. It does not certify against kernel privilege escalation or zero-day breakouts.


              2. Chain Tamper-Evidence: SHA-256 hash chaining detects modifications relative to genesis.
              It does not prevent full-chain replacement without an external trusted anchor.


              3. macOS VirtioFS Translation: Docker Desktop on macOS translates file permissions across host
              bind mounts. BREACHLINE mitigates this via a container-initialized volume (breachline-fixture-vol).
